# 🚀 TaskPilot AI

> An AI-powered productivity assistant for smarter planning, task management, and focused work.

## 📌 About

TaskPilot AI is an intelligent productivity platform designed to help users organize tasks, plan schedules, build routines, and stay focused.

It combines task management with Google Gemini-powered AI assistance to turn natural-language requests into actionable plans.

## ✨ Features

- 🤖 AI Assistant for intelligent planning
- 📝 Smart task management
- 📅 Calendar and schedule planning
- 🎯 Focus sessions
- 🔄 Routine management
- 📊 Productivity insights
- 🔐 Authentication
- ⚙️ Personalized settings
- 🧠 Google Gemini integration

## 🛠️ Tech Stack

- **Frontend:** Next.js, React, TypeScript
- **Styling:** Tailwind CSS
- **AI:** Google Gemini
- **Backend / Database:** Supabase
- **Package Manager:** pnpm
- **Deployment:** Vercel
